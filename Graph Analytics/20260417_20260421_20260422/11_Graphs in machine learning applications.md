The transformation from structured or unstructured data to a graph representation can be performed in a lossless manner, but this loss less representation is not always necessary (or desirable) for the purpose of the learning algorithm.

## Visualizzazione

La visualizzazione è un tool utile per effettuare analisi sui dati, tuttavia non è un tool completo.
Un problema legato alla visualizzazione è il cosiddetto "hairball problem", ovvero un problema che nasce dal fatto che più dati abbiamo meno riusciamo a trovare delle informazioni, in quanto con tantissimi collegamenti si vanno a sovrapporre i nodi.
Altri problemi possibili sono le "snowstorms", problema derivante dalla creazione di tantissime micro-community in quanto il grafo è poco connesso e le "starburst", problema in cui tantissimi nodi sono collegati a uno solo, creando una sorta di stella.
