We are given a training set $\{ X_{i}, Y_{i}\ \} _{i=1}^{N}$, with $X_i \in \mathbb{R}^{m}$ and $Y_{i} \in \{ 0; 1 \}$ for each $i = 1, \dots, N$.

- $N$ is the number of training examples
- Each sample $X_i = \{ x_{i}^{(1)}, \dots, x_{i}^{(m)} \}$ is a vector of $m$ features
- Each label $Y_i$ is either 0 or 1
